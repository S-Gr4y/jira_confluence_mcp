# Jira Standup Update

1. Use `jira_search_issues` with a JQL query for the user's active or recently updated issues.
2. Group issues by status or workstream.
3. Identify completed work, current focus, and blockers from issue fields and recent context.
4. Draft a concise update with issue keys and URLs.
5. Do not post the update unless the user explicitly asks and approves the exact text.
